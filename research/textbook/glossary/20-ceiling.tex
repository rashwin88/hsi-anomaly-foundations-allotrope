\glossentry{1x1 convolution}{A convolution whose kernel covers a single pixel, so it applies the same weighted sum of channels at every position; the spectral compressor is one.}
\glossentry{Linear map}{A map f with f(ax + cy) = a f(x) + c f(y); its sensitivity to each input is a constant, the same for every input vector.}
\glossentry{Rank}{The number of linearly independent rows (equivalently columns) of a matrix; a 32 x 165 matrix has rank at most 32.}
\glossentry{Null space}{The set of vectors a matrix maps to zero; spectral differences lying in the compressor's null space are invisible to it.}
\glossentry{Rank-nullity theorem}{For a matrix with N columns, rank plus the dimension of the null space equals N.}
\glossentry{Fixed recipe}{This book's name for a fixed linear compressor's mixing weights: the same weighted sum of bands for every pixel.}
\glossentry{Fill value}{A substitute number written into a dead or missing band so that a fixed-size layer can accept the pixel; it is not a measurement.}
\glossentry{Cross-attention}{Attention whose queries come from a different source than its keys and values; M queries over N tokens give M outputs whatever N is.}
\glossentry{Self-attention}{Attention in which queries, keys and values all come from the same set of tokens, giving one output per token.}
\glossentry{Learned query}{A query vector stored as a trained parameter rather than computed from the input; the spectral compressor has 32 of them.}
\glossentry{Attention weights}{The softmax of scaled query-key scores; each row is positive and sums to 1.}
\glossentry{Convex combination}{A weighted sum whose weights are non-negative and sum to 1; it always lies between the smallest and largest of the values combined.}
\glossentry{Permutation invariance}{The property that reordering the keys and values (together) does not change an attention output.}
\glossentry{Band token}{One band of one pixel represented as a d-number vector: its value stretched by Linear(1, d), plus the encoding of its wavelength.}
\glossentry{Token width}{The number of components d in each token; 32 in the spectral stem.}
\glossentry{Value stretch}{The Linear(1, d) layer that turns one reflectance number into a d-number vector; 64 parameters at d = 32.}
\glossentry{Wavelength encoding}{A fixed vector of sines and cosines of 2 pi lambda / P over 16 geometric periods P from 10 to 10,000 nm; sines first, then cosines.}
\glossentry{Period}{The distance, in nm, after which a sine or cosine repeats; the encoding uses five periods per decade.}
\glossentry{Aliasing}{Two different inputs giving the same encoding because a wave has completed a whole number of periods between them.}
\glossentry{Cosine similarity}{The dot product of two vectors divided by the product of their lengths; for two wavelength tags it depends only on their wavelength difference.}
\glossentry{Shift invariance}{The property of the wavelength encoding that the similarity of two tags depends only on the difference of their wavelengths.}
