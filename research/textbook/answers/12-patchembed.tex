\begin{solution}{ex:patchembed:1}
Stage~1 ($k=s=4$, $p=0$): $\lfloor(96-4)/4\rfloor + 1 = \lfloor 23\rfloor + 1 = 24$, so a
$24\times24$ grid and $24\times24 = 576$ tokens.

Stages~2 to~4 ($k=3$, $s=2$, $p=1$):
\begin{align*}
\text{stage 2: } & \lfloor(24 + 2 - 3)/2\rfloor + 1 = \lfloor 11.5\rfloor + 1 = 12, & 12^2 &= 144,\\
\text{stage 3: } & \lfloor(12 + 2 - 3)/2\rfloor + 1 = \lfloor 5.5\rfloor + 1 = 6, & 6^2 &= 36,\\
\text{stage 4: } & \lfloor(6 + 2 - 3)/2\rfloor + 1 = \lfloor 2.5\rfloor + 1 = 3, & 3^2 &= 9.
\end{align*}
\end{solution}

\begin{solution}{ex:patchembed:2}
\code{Conv2d(64, 160, kernel_size=3)}:
\begin{align*}
64\times160\times9 &= 10{,}240\times9 = 92{,}160,\\
92{,}160 + 160 &= 92{,}320,
\end{align*}
plus LayerNorm $2\times160 = 320$: total $92{,}640$, stage~3's figure.

Stage~1 reading 24 channels:
\begin{align*}
24\times32\times16 &= 768\times16 = 12{,}288,\\
12{,}288 + 32 &= 12{,}320,\\
12{,}320 + 64 &= 12{,}384.
\end{align*}
\end{solution}

\begin{solution}{ex:patchembed:3}
$(1,3,5,7)$: mean $(1+3+5+7)/4 = 16/4 = 4$. Deviations $-3, -1, 1, 3$; squares $9, 1, 1, 9$; sum
$20$; variance $20/4 = 5$; standard deviation $\sqrt5 = 2.23607$. Outputs:
\begin{align*}
-3/2.23607 &= -1.3416, & -1/2.23607 &= -0.4472,\\
1/2.23607 &= 0.4472, & 3/2.23607 &= 1.3416.
\end{align*}
$(10,30,50,70)$: mean $160/4 = 40$; deviations $-30,-10,10,30$; squares $900,100,100,900$; sum
$2000$; variance $500$; standard deviation $\sqrt{500} = 22.3607$. Outputs $-30/22.3607 = -1.3416$,
$-0.4472$, $0.4472$, $1.3416$: identical. The second token is ten times the first; LayerNorm divides out
each token's own scale (and subtracts its own mean), so only the pattern across features survives.
\end{solution}

\begin{solution}{ex:patchembed:4}
Top-left block $\begin{pmatrix}4&0\\4&0\end{pmatrix}$: average $0.25\times(4+0+4+0) = 0.25\times8 = 2$;
left minus right $(4+4) - (0+0) = 8$.

Top-right $\begin{pmatrix}1&1\\1&1\end{pmatrix}$: average $0.25\times4 = 1$; left minus right
$(1+1)-(1+1) = 0$.

Bottom-left $\begin{pmatrix}2&2\\2&2\end{pmatrix}$: average $0.25\times8 = 2$; left minus right $0$.

Bottom-right $\begin{pmatrix}0&3\\0&3\end{pmatrix}$: average $0.25\times6 = 1.5$; left minus right
$(0+0) - (3+3) = -6$.

Token sequence, shape \shape{(1, 4, 2)}:
\[
\begin{pmatrix}2 & 8\\ 1 & 0\\ 2 & 0\\ 1.5 & -6\end{pmatrix}.
\]
\end{solution}

\begin{solution}{ex:patchembed:5}
Window $n$ starts at original pixel $4n - 1$ and covers six pixels, $4n-1$ to $4n+4$:
\begin{align*}
n=0&: -1..4 \ \to\ 0..4 \text{ real},\\
n=1&: 3..8,\\
n=2&: 7..12 \ \to\ 7..11 \text{ shown},\\
n=3&: 11..16 \ \to\ 11 \text{ shown}.
\end{align*}
Counts for pixels $0..11$:
\[
1\ 1\ 1\ 2\ \ 2\ 1\ 1\ 2\ \ 2\ 1\ 1\ 2 .
\]
Token~1's block is pixels $4..7$. Pixel~4 is also in window~0 and pixel~7 in window~2; pixels~5 and~6
are only in window~1. So two of the four pixels per row leak if both neighbours are visible. (The grid is
still $\lfloor(128 + 2 - 6)/4\rfloor + 1 = 31 + 1 = 32$ on a side, so a size check would not catch the
leak.)
\end{solution}

\begin{solution}{ex:patchembed:6}
After \code{flatten(2)} the token tensor no longer records that its $N$ tokens came from an
$H'\times W'$ grid, and later modules (attention's spatial reduction, the Mix-FFN depthwise
convolution) must reshape the tokens back into that grid; so the grid size is returned and carried
explicitly. LayerNorm normalises each token over its own features, so a token's output does not depend
on other examples in the batch or on how many tokens masking deleted; BatchNorm would couple tokens
across the batch and change behaviour between training and evaluation.
\end{solution}
