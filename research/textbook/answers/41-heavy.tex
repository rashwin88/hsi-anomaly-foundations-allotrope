\begin{solution}{ex:heavy:1}
Stage 2 has $R=4$, so the $C^2$ coefficient is $12+16=28$.
\begin{align*}
\text{FT04, } C=64 &: 28\times64^2+56\times64 = 28\times4{,}096+3{,}584 = 114{,}688+3{,}584 = 118{,}272\\
\text{Heavy, } C=192 &: 28\times192^2+56\times192 = 28\times36{,}864+10{,}752 = 1{,}032{,}192+10{,}752 = 1{,}042{,}944\\
\text{ratio} &: 1{,}042{,}944/118{,}272 = 8.82
\end{align*}
Both match the table. Doubling stage 1 ($C=32\to64$): the $C^2$ term $77{,}824\times4=311{,}296$, the $C$ term
$1{,}792\times2=3{,}584$, total $314{,}880$; ratio $314{,}880/79{,}616=3.95$, a little under $2^2=4$.
\end{solution}

\begin{solution}{ex:heavy:8}
On 2 threads: $(1-0.923)+0.923/2=0.077+0.4615=0.5385$. On 24: $0.077+0.923/24=0.077+0.0385=0.1155$. Speed-up
$0.5385/0.1155=4.66$ (4.67 with $p$ unrounded), against 4.0 at 16. Reasons for doubt: $p$ was fitted to a single
measurement, and the law ignores memory bandwidth, which threads share; and 24 threads on a 24-core host leave
nothing for the api, the database and the operating system, which is why the compose file chose 16 for headroom.
\end{solution}

\begin{solution}{ex:heavy:9}
The output network is $32\to64\to(D+1)$ on the wavelength encoding. With $D=32$:
\begin{align*}
32\times64+64 &= 2{,}048+64 = 2{,}112\\
64\times33+33 &= 2{,}112+33 = 2{,}145\\
2{,}112+2{,}145 &= 4{,}257,
\end{align*}
FT04's \texttt{spectral\_out} in \cref{tab:heavy:total}. FT04's segmentation head, width 128, $5\times16=80$ sub-pixel
channels:
\begin{align*}
\text{projections} &: (32+64+160+256)\times128+4\times128 = 512\times128+512 = 65{,}536+512 = 66{,}048\\

\end{align*}
the head counted in \cref{ch:shipping}.
\end{solution}

\begin{solution}{ex:heavy:10}
Each pass hides half of the 1,024 valid tokens and keeps 512. Stage~1 then attends among the kept tokens:
$512^2=262{,}144$ scores per head, 16 times the unmasked $1{,}024\times16=16{,}384$. A batch of 8 tiles gives the stem
$8\times128\times128=8\times16{,}384=131{,}072$ rows, and $131{,}072/32{,}768=4$ calls of the attention kernel.
\end{solution}
