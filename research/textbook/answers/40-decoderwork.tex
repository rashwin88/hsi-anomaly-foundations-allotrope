\begin{solution}{ex:decoderwork:1}
Quantile level $0.99$; position $0.99\times(200-1)=197.01$, so the cut lies 1\% of the way from $x_{(197)}$ to
$x_{(198)}$ (counting from 0). The values at or above it are $x_{(198)}$ and $x_{(199)}$: 2 pixels, 1\% of 200.
With \texttt{gate\_halo = 1} the kernel is $2\times1+1=3$, so each becomes a $3\times3$ square of 9 pixels:
$9+9=18$ loss pixels removed at most. Under L1 every loss pixel carries a gradient of the same size, so the
share of gradient terms removed is $18/200=0.09$, 9\%.
\end{solution}

\begin{solution}{ex:decoderwork:2}
Tokens per side $256/4=64$, tokens $64\times64=4{,}096$. Blocks per side $64/2=32$, blocks $32\times32=1{,}024$.
Hidden blocks $1{,}024\times0.65=665.6\to665$; hidden tokens $665\times4=2{,}660$, a share
$2{,}660/4{,}096=0.649$.

Blocks: given our block is hidden, the other $1{,}023$ blocks contain $1{,}024-665=359$ visible ones. Five outside
neighbours: $5\times359/1{,}023=5\times0.3509=1.755$.

Single tokens: hidden $4{,}096\times0.65=2{,}662.4\to2{,}662$, visible $4{,}096-2{,}662=1{,}434$. Given ours is
hidden, the other $4{,}095$ contain $1{,}434$ visible: $8\times1{,}434/4{,}095=8\times0.3502=2.801$.
The ratio $1.755/2.801=0.63$, as for the 128\,px tile.
\end{solution}

\begin{solution}{ex:decoderwork:7}
Blocks per side $6/2=3$, blocks $3\times3=9$. In each block $h$ is the same for all 4 tokens and $s$ takes each
value twice, so 2 tokens leak per block: $9\times2=18$ of $6\times6=36$ tokens, $18/36=0.5$. Swapping which pass
hides which blocks flips $h$ in every block from 0 to 1 or back; $s$ still takes each value on 2 of the 4 tokens,
so still 2 agree and 2 disagree. Only the positions of the leaks move, not their number.
\end{solution}
